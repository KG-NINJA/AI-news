# 世界情勢まとめ

**【背景】**
中東のイエメンでは、フーシ派が支配地域を拡大すべく最前線の都市で激しい戦闘を続けており、地政学的な緊張が極限に達しています。一方、東欧のセルビアでは、アレクサンダル・ブチッチ大統領が辞任を発表し、早期総選挙へと舵を切りました。これは、国内での相次ぐ銃乱射事件後の抗議デモや、対コソボ政策への圧力に直面する中で、自身の支持基盤を再固めし、政権の正統性を主張するための政治的な「賭け」であると分析されています。

**【今後のポイント】**
