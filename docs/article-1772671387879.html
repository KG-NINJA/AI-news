# 世界情勢まとめ

**【背景：イラン情勢の決定的な悪化と直接衝突】**
中東情勢は、これまでの「代理戦争」の枠組みを完全に超え、国家間の直接的な武力衝突という最悪のフェーズに突入しています。
ハメネイ師の葬儀延期は、イスラエルおよび米国による爆撃がイラン国内の重要拠点に対して継続的かつ容赦なく行われていることを示唆しており、イラン指導部の統制能力が著しく低下している可能性があります。
さらに、ピート・ヘグセス国防長官が言明した「米潜水艦によるイラン軍艦の撃沈」は、米国が後方支援に留まらず、インド洋という広域で直接的な軍事行動に踏み切ったことを意味します。これは、トランプ政権（およびその準備期間）下での「圧倒的な武力行使による抑止」へのシフトを象徴する出来事です。

**【今後のポイント】**
1. **イランの権力空白と体制崩壊：** 最高指導者の葬儀すら行えない混乱の中で、イラン国内の体制維持が限界に達し、政権崩壊や大規模な内部抗争に発展するリスクが高まっています。
2. **海上交通路（シーレーン）の封鎖リスク：** インド洋での戦闘は、ホルムズ海峡や紅海に続くエネルギー輸送の動脈に直接影響を与えます。原油価格の急騰など、世界経済への波及が懸念されます。
3. **米国の直接介入の拡大：** 米軍が「撃沈」という直接的な攻撃を選択したことで、今後イスラエルとの共同作戦がさらに激化し、地域紛争が全面戦争へと拡大する瀬戸際にあります。
